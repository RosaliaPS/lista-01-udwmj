## Descrição do Código

Este repositório contém uma aplicação web simples desenvolvida em HTML5, CSS3 e JavaScript contida no arquivo `index.html`.

### Funcionalidades:
- **HTML:** Estrutura uma interface simples contendo um título, texto informativo, um botão interativo e uma área para exibir o resultado.
- **CSS:** Realiza a estilização centralizada e responsiva da página, aplicando sombras, cantos arredondados e efeitos de hover no botão.
- **JavaScript:** Adiciona interatividade à página capturando o evento de clique do botão através do `addEventListener` e atualizando o contador dinamicamente na tela sem recarregar a página.
