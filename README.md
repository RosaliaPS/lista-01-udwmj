# lista-01-udwmj
Este repositório foi criado para a realização da Lista de Exercícios I da disciplina de Usabilidade, Desenvolvimento Web, Mobile e Jogos.

## Código JavaScript

O código cria duas variáveis, `numero1` e `numero2`, com os valores 10 e 5. Em seguida, realiza a soma desses dois números e armazena o resultado na variável `soma`.

Por fim, o resultado da soma é exibido no console utilizando `console.log()`.
